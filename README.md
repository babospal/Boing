# Boing!
### Bounce Back!

Welcome to **Boing!**, a puzzle game where thinking outside the box is the key to bouncing your way to victory!

## About the Game

You have to solve puzzles by strategically placing trampolines to bounce your way through each level.


**Just Boing! your way through!**

## Game Features

- Trampoline-based puzzle mechanics
- 6 levels
- 4 different trampolines
